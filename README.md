# 💰 مدرب الفلوس — GTA 6

بوت تيليجرام شخصي يساعدك تجمع فلوس بسرعة في GTA 6 وتتطور في اللعب.

## وش يسوي
- **يجاوب أسئلتك** بالعربي ويبحث في الويب عن أحدث الأدلة.
- **يقرأ صور الشاشة**: صوّر التلفزيون وأرسل، ويقول لك وش تسوي.
- **يعرف وين وصلت**: يسجل فلوسك ومرحلتك وهدفك من كلامك تلقائياً، وما يحرق عليك القصة.
- **خطة جلسة**: `/plan 60` يعطيك خطة فلوس لساعة لعب.
- **تقرير يومي** بالوقت اللي تحدده: أفضل طرق الفلوس لمرحلتك، الجديد، وخطة الليلة.
- **تنبيه قلتشات** ⚡: يشيك كل 4 ساعات على Reddit ويوتيوب والمواقع، ويتأكد قبل ما ينبهك.
- **لك بروحك**: يتجاهل أي أحد غيرك.

## الملفات
| الملف | الدور |
|---|---|
| `bot.py` | تشغيل البوت والأوامر والجدولة |
| `brain.py` | الكلام مع Claude + البحث + أدوات تحديث ملفك |
| `daily.py` | التقرير اليومي |
| `glitches.py` | مراقب القلتشات |
| `sources.py` | قراءة RSS و Reddit ويوتيوب |
| `db.py` | قاعدة البيانات (SQLite) |
| `prompts.py` | شخصية البوت وتعليماته |
| `config.py` | الإعدادات والمصادر |

## التشغيل

### 1) جهز المفاتيح
1. **بوت تيليجرام**: كلّم [@BotFather](https://t.me/BotFather) → `/newbot` → خذ التوكن.
2. **Claude API**: من [console.anthropic.com](https://console.anthropic.com) → API Keys. وفعّل Web search من إعدادات المنظمة، وحط حد صرف شهري (مثلاً 25$).
3. **يوتيوب (اختياري)**: Google Cloud → فعّل YouTube Data API v3 → أنشئ API key.

### 2) جرّب على جهازك
```bash
pip install -r requirements.txt
cp .env.example .env   # واملأ القيم
export $(grep -v '^#' .env | xargs)
python bot.py
```
أرسل `/myid` للبوت، حط الرقم في `OWNER_ID`، وأعد التشغيل.

### 3) على Railway (لما تقرر)
- خدمة جديدة من المجلد أو الريبو، تشتغل كـ worker (`Procfile` جاهز).
- أضف Volume على `/data` وحط `DB_PATH=/data/bot.db` عشان ما تضيع بياناتك مع كل نشر.
- حط المتغيرات من `.env.example`.

## التكلفة التقريبية
حوالي **15–20$ بالشهر** لاستخدام يومي (Haiku للأسئلة، Sonnet للصور والتقارير). أكبر بند هو البحث في الويب (حوالي سنت للبحث).

## ملاحظات
- أي مصدر RSS يفشل، البوت يتجاهله ويكمل. تقدر تضيف مصادر بـ `EXTRA_FEEDS`.
- Reddit أحياناً يحجب السيرفرات؛ لو صار، البوت يكمل بالمصادر الثانية والبحث.
- القلتشات للعب الفردي فقط، ودايماً احفظ نسخة احتياطية قبل تجربتها.
